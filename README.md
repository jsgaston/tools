# tools

Wisfli tools for MetaTrader 5, published with GitHub Pages at https://jsgaston.github.io/tools/

- `index.html` — list of tools
- `trading-command-center/index.html` — product page and checkout (edit the `CHECKOUT` block at the end of the file)
- `trading-command-center/terms.html` — licence terms, privacy and risk

Files are delivered by email by the licensing system (`api.wisfli.com`). No `.ex5` goes in this repo.
