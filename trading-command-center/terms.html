Licence terms

What you are buying

A personal, non-transferable licence to use the Trading Command Center Expert Advisor for MetaTrader 5, delivered by email as a compiled .ex5 file together with a licence key. You are not buying the source code or any rights in it.

Plans and scope

  • Monthly subscription: valid while the subscription is paid. If you cancel, the licence keeps working until the end of the period already paid and then stops.
  • Lifetime licence: no expiry.
  • Both plans: one key can be linked to up to three live accounts and three demo accounts at the same time, with every feature and all updates included.
  • Accounts link automatically the first time the EA runs on them. You can free a linked account from your licence page up to three times in any 30-day period; a demo account unused for 30 days is freed automatically.

How the licence is checked

The EA checks the key with the Wisfli licence server when it starts and every few hours. If the server cannot be reached, the last valid check is trusted for up to 72 hours. Without a valid licence the EA stays loaded but sends no messages and accepts no commands.

Breaching any of these revokes the licence with no refund.
